# 识图取数 · 使用说明

把 POCIB 客户端窗口上的「公司资料 / 商品资料」，自动认成可以填进网页助手的数据。

## 怎么用

1. 把 POCIB 客户端切到 **基本资料**（注册公司）或 **商品信息** 页面，窗口**不要最小化**。
2. 双击 **`识图取数.bat`**。
3. 看到「已复制到剪贴板」后，回到 `POCIB填单助手.html`，点左栏的
   **📷 截图识别公司信息**（或商品组里的 **📷 截图识别商品**）。
4. 在弹窗输入框里按 **Ctrl+V** 粘贴，点「解析」。
5. 逐项核对 → 需要改的直接改 → 点「填入选中的项」。

第一次运行会自动装中文识别模型（约 120MB，只装一次）。装不上时会自动退回系统自带
OCR（能认，但中文精度差一些）。

## 命令行用法

```bat
识图取数.bat                      :: 自动找 POCIB 窗口
识图取数.bat --list               :: 列出当前能识别的窗口
识图取数.bat --hwnd 123456        :: 指定窗口句柄
识图取数.bat --kind goods         :: 强制按商品档案解析
识图取数.bat --file 截图.png      :: 直接认一张图（Win+Shift+S 存的 PNG）
识图取数.bat --clip               :: 认剪贴板里的截图
识图取数.bat --engine win         :: 用 Windows 自带 OCR（不装模型）
识图取数.bat --save-img           :: 顺便把截图存到结果旁边，方便对照
```

结果同时写进三处：桌面上的 `POCIB识别_日期时间.json`、剪贴板、控制台。

## 精度说明

- 账号、税号、海关登记号、信用代码、电话传真邮编、银行名称、地址：实测基本全对。
- 公司介绍、规格型号这类长段落，换行归位偶尔会串到隔壁栏，核对时留意。
- 认不出的字段不会瞎填：留空，或者标成「低」置信且默认不勾选。
- 币别有时认不出来（软件里那行字太小），程序会按国家推导（德国→EUR、美国→USD…），
  标成「推导」，核对一下即可。

## 文件说明

| 文件 | 作用 |
|---|---|
| `识图取数.bat` | 双击入口，自动检查 Python / 装模型 |
| `extract.py` | 主流程：找窗口 → 截图 → 识别 → 解析 → 输出 |
| `ocrlib.py` | 截图（PrintWindow）、PNG 读写、缩放、OCR 封装 |
| `parse.py` | 版面还原：行、单元格、标签冒号切分、字段模糊匹配 |
| `ocr.ps1` | 系统自带 OCR 的封装（无需安装，作为备胎） |
| `self_test.py` | 解析规则自测（不需要截图） |

## 隐私

全部在本机完成，不联网上传；截图只放在临时目录，用完即删（除非加 `--save-img`）。
